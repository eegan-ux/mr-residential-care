# MR Residential Care

Marketing website for MR Residential Care — Supported Living & Habilitative
Support services in Clackamas County, Oregon.

Built with Next.js 14 (App Router), TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push this repo to GitHub, then import it in [Vercel](https://vercel.com/new) —
no configuration needed, Vercel auto-detects Next.js.

## Structure

- `app/` — routes, layout, global styles
- `components/` — page sections (Navbar, Hero, About, Services, WhyUs, ReferralCTA, Footer)
- `public/mr-logo.png` — site logo
